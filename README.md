## ✨ Características del Portafolio

- **Diseño Moderno**: Interfaz limpia y profesional con efectos glassmorphism
- **Terminal Interactiva**: Efecto bash en la sección hero con animaciones secuenciales
- **Totalmente Responsive**: Se adapta perfectamente a todos los dispositivos
- **Navegación Suave**: Scroll suave entre secciones
- **Animaciones Interactivas**: Efectos de entrada, contadores animados y barras de progreso
- **Estimador de Costos**: Calculadora interactiva para cotizar proyectos web
- **Formulario de Contacto**: Con validación y notificaciones
- **Optimizado para SEO**: Estructura semántica y meta tags
- **Sin Dependencias**: Solo HTML, CSS y JavaScript vanilla

## 🎨 Secciones Incluidas

## 🎯 Personalización

### 1. Información Personal

Edita el archivo `index.html` y cambia:

```html
<!-- En la sección Hero -->
<div class="terminal-line output-line" id="output1">
    <span class="output">Tu Nombre Completo</span>
</div>

<!-- En la sección About -->
<p>Soy un ingeniero en desarrollo...</p>

<!-- En la sección Contact -->
<span>tuemail@ejemplo.com</span>
<span>+52 XXX XXX XXXX</span>
<span>Tu Ciudad, México</span>
```

### 2. Proyectos

Modifica la sección de proyectos con tus trabajos reales:

```html
<div class="project-card">
    <div class="project-image">
        <i class="fas fa-laptop-code"></i>
    </div>
    <div class="project-content">
        <h3>Nombre del Proyecto</h3>
        <p>Descripción del proyecto...</p>
        <div class="project-tech">
            <span class="tech-tag">Java</span>
            <span class="tech-tag">Spring</span>
            <span class="tech-tag">Angular</span>
        </div>
        <div class="project-links">
            <a href="#" class="project-link"><i class="fas fa-external-link-alt"></i> Demo</a>
            <a href="#" class="project-link"><i class="fab fa-github"></i> Código</a>
        </div>
    </div>
</div>
```

### 3. Habilidades

Ajusta las barras de progreso en la sección de habilidades:

```html
<div class="skill-item" data-tech="java">
    <div class="skill-icon">
        <i class="fab fa-java"></i>
    </div>
    <h4>Java - Spring Framework</h4>
    <div class="skill-bar">
        <div class="skill-progress" style="width: 90%"></div>
    </div>
</div>
```

### 4. Estimador de Costos

Personaliza los precios en `script.js`:

```javascript
const projectPrices = {
    landing: 500,
    corporate: 800,
    ecommerce: 1500,
    blog: 600,
    portfolio: 400,
    custom: 2000
};
```
